# 肿瘤检测与分割算法

## 1. 项目概述
本项目实现了一个用于医学图像肿瘤检测和分割的自动化流水线。系统采用最先进的 YOLOv8 模型分别进行目标检测和实例分割，以确保高灵敏度和精确度。

## 2. 算法描述

### 2.1 目标检测 (YOLOv8m)
- **模型架构**: YOLOv8m (中型版本)
- **训练策略**: 使用提供的肿瘤数据集进行训练，并优化了超参数。
- **推理**: 执行边界框回归以识别潜在的肿瘤区域。使用 0.25 的置信度阈值来平衡精确率和召回率。

### 2.2 实例分割 (YOLOv8n-seg)
- **数据集构建**: 由于原始数据集缺乏像素级标注，我们开发了一个半自动标注流程：
    1.  **自动分割**: 使用 **GrabCut** 算法，以真值边界框（Ground Truth Bounding Box）初始化，提取前景掩码。
    2.  **数据集生成**: 将掩码转换为 YOLO 分割格式（多边形）。
- **模型架构**: YOLOv8n-seg (Nano版本) 用于高效分割。
- **推理**: 生成肿瘤区域的像素级掩码。应用 0.35 的置信度阈值。

### 2.3 结果融合
为了最大化检测性能，采用了 **逻辑“或”融合 (Logical OR Fusion)** 策略：
- 如果 **检测模型** 或 **分割模型** 中任意一个识别出图像中的肿瘤，则该图像被分类为 **阳性 (Tumor)**。
- 这种方法利用了两种模型的互补优势：检测模型擅长通用定位，而分割模型能捕捉细粒度特征。

## 3. 目录结构

- **`src/`**: 源代码目录。
    - **`main.py`**: 主要入口点。负责模型加载、推理、结果融合和 CSV 生成。
    - **`cam.py`**: 可视化和掩码处理工具。
    - **`seg_yolov8.py`**, **`inference.py`**, **`utils.py`**: 辅助模块。
- **`models/`**: 包含训练好的模型权重。
    - **`det_best.pt`**: YOLOv8m 检测权重。
    - **`seg_best.pt`**: YOLOv8n-seg 分割权重。
- **`doc/`**: 文档文件。

## 4. 运行方式

要在测试数据集上运行推理流水线，请将 `"path/to/images"` 替换为您的图像目录的实际路径。

```bash
python src/main.py --data "path/to/images" --out ./输出结果/cla_pre.csv
```

### 示例:
```bash
python src/main.py --data "正式题数据集/no" --out ./输出结果/cla_pre.csv
```

### 参数说明:
- `--data`: 包含测试图像的目录路径。默认为 `./测试数据集`。
- `--out`: 输出 CSV 文件的保存路径。默认为 `./输出结果/cla_pre.csv`。
- `--det-weights`: (可选) 检测模型权重的路径。
- `--seg-weights`: (可选) 分割模型权重的路径。
- `--save`: (可选) 是否保存可视化的检测和分割结果图片。

## 5. 输出格式
输出文件 (`cla_pre.csv`) 遵循以下格式：
```csv
filename,label
image_001.jpg,1
image_002.jpg,0
...
```
- **label**: `1` 表示有肿瘤 (Tumor)，`0` 表示正常 (Normal)。
